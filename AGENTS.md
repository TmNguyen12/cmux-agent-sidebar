# Agent instructions

## Commits and PRs

- Start every commit message and PR title with a Conventional Commits type: `feat:`, `fix:`, `docs:`, `test:`, `refactor:`, `perf:`, `chore:`. Squash merge turns the PR title into the commit on `main`, so the title needs it too.
- Example: `fix: group a Claude Code worktree under its repo, named by its folder`.
